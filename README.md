# Automated FPL Analyser

This project is designed to run automated analysis on your FPL team and give you customised suggestions using ML

## Prerequisites

- Python 3.14
- [UV](https://astral.sh/uv/)
- [pre-commit](https://pre-commit.com/#install)

## Usage

### Setup

The dev environment can be set up using the following commands
```bash
uv sync
uv pip install -e .
pre-commit install
```
